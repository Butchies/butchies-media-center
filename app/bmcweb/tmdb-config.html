TMDb-Metadaten

Lädt Filmplakate, Hintergrundbilder, Logos, Beschreibungen, Genres, Altersfreigaben und Schauspieler von themoviedb.org. Eigene .nfo-Dateien und Bilder neben den Filmen haben immer Vorrang. Deine Dateien werden nicht verändert – alles Heruntergeladene liegt im Datenordner des Media Centers.

So bekommst du einen kostenlosen Schlüssel: auf themoviedb.org ein Konto anlegen → Einstellungen → API → „API-Schlüssel“ (oder „API-Lesezugriffstoken“) kopieren und hier einfügen.

Leer lassen = keine Daten aus dem Internet.
